# 批量采集使用说明（Temu → 1688 → Excel）

把 Temu「已发布到站点」的商品，逐个到 1688 以图搜图找采购价、估重量，按原表公式写入
`商品成本核算_原始备份.xlsx` 的「pawly全球」表。支持一次处理上百个商品。

---

## 一、两个入口，按场景选

| 场景 | 用哪个 |
|---|---|
| **批量采集很多商品**（主力） | `python batch_collect.py` |
| 单个 / 临时 / 补漏 / 改某一条 / 其它任务 | `python main.py`（交互式 agent） |

两者底层是**同一个 agent + 同一套工具/提示词/经验**，`batch_collect.py` 只是多了
「枚举 + 循环 + 每商品隔离上下文 + 去重续跑」的编排层，改进（见下）两边共享。

---

## 二、前置条件

1. **先关掉 WPS/Excel 里打开的那个 `商品成本核算_原始备份.xlsx`**。
   文件被占用会写不进（Permission denied）；驱动有占用预检，会直接报错让你先关。
2. 浏览器：已用远程调试端口启动、并登录好 Temu 和 1688 的 Chrome
   （`--remote-debugging-port=9222`，配置见 `config/config.toml` 的 `cdp_url`）。

---

## 三、批量采集 `batch_collect.py`

### 常用命令
```bash
# 只枚举列表（不采购、不写表），检查清单质量
python batch_collect.py --enumerate-only

# 冒烟：只采 1 个，端到端验证
python batch_collect.py --limit 1

# 放量：一批 20 个未入库商品（复用已有清单）
python batch_collect.py --limit 20

# 先重新枚举最新列表，再采 20 个（Temu 上新了商品时用）
python batch_collect.py --refresh --limit 20
```

### 参数
- `--limit N`：本批处理 N 个**未入库**商品（默认 20）。**建议 20~30/批**，别一次几百——小批更稳、可续、出错影响小。
- `--refresh`：重新枚举 Temu 列表（写 `workspace/worklist.json`）。只在有新品上架、清单需更新时用；否则省掉、直接复用现有清单。
- `--enumerate-only`：只枚举、不采购。

### 典型流程
```bash
# 0. 关掉 WPS 里的 Excel
# 1. 重新枚举 + 采第一批
python batch_collect.py --refresh --limit 20
# 2. 继续下一批（自动跳过已采的）
python batch_collect.py --limit 20
python batch_collect.py --limit 20   # …重复直到采完
# 3. 打开 Excel 核对新行
```

### 关键特性
- **幂等 / 断点续跑**：每次开跑前读 Excel 已入库 SPU，已采的自动跳过。任何时候中断、崩溃，再跑一次就从没采的继续，只丢当前正在处理的那一个。
- **每商品独立上下文**：逐个处理、跑完清空对话记忆，上下文不累积（单商品约 12 步 / 48 万 token）。这正是能扛上百个而不会上下文爆炸的原因。
- **确定性枚举**：直接命中 Temu 列表后端接口取全量（实测 185/185 完整），不靠 agent 滚动虚拟列表（那样只能拿到零头、还极费 token）。枚举阶段 0 LLM 开销。

## 四、采集规则（已内置在提示词与经验里）

- **1688 以图搜图**：用 `paste_image`（系统剪贴板 + 真实 Ctrl+V），不走文件上传（会弹系统对话框卡死浏览器）。
- **采购价 = 常规批发价 + 运费**：剔除「新人价 / 首单价 / 首单减X / 优惠券 / 秒杀价」这类只对首单有效、有欺骗性的优惠。
- **重量靠推测**：不照抄平台标注（普遍不准），据尺寸/体积、材质、填充物推测。
- **同款过滤**：结果里先滤掉不相干品类（笔袋/文具/挂件等），只在真正同款里挑最便宜。
- **红线**：只读价格，**绝不下单 / 支付**。
- **及时清标签**：每采完一个 `close_tabs(text="1688")` 关掉该商品开的 1688 标签。

## 五、产物存放（桌面 `manus输出/`）

所有生成物集中分类，不散落桌面：
```
桌面/manus输出/
├── Excel备份/     ← 每次写表前的时间戳备份（自动）
├── 商品图片/       ← 下载的商品主图（按 SPU 命名）
└── 调试截图/       ← gui_action 调试截图
```
> 想换位置：设环境变量 `MANUS_OUTPUT_DIR` 即可。

## 六、交互式 agent `main.py`（零散/特殊任务）

```bash
python main.py                          # 手动输入指令
python main.py --prompt "把xxx商品..."    # 直接给指令
python main.py --max-steps 60           # 复杂任务放宽步数
```
用于单独补采/修正某个商品、换站点或表、临时一次性任务等。

---

## 七、排错

| 现象 | 原因 / 处理 |
|---|---|
| `Permission denied: ...xlsx` | Excel 被 WPS 打开锁着。**关掉它再跑**。 |
| 枚举条数为 0 / 缺 mallid | 未登录 Temu，或列表页没加载出来。先在浏览器里打开并登录 Temu 后台。 |
| 某商品「未见于 Excel」 | 该商品这轮采集失败（如没找到同款）。不影响其它，下轮会重试（它没进 Excel，仍算未入库）。 |
| 想重来某个已入库商品 | 先在 Excel 删掉它那行，再跑（判重按 Excel 里的 SPU）。 |
