manus-gui 使用说明
================================================

一、这个包是什么
------------------------------------------------
自包含的绿色版：Python 运行时和全部依赖都已内置，解压即用，
不需要在新电脑上安装 Python，也不需要 pip install。

三个可执行文件：
  manus-web.exe    Web 界面（采集 / 订单 / 活动 / agent 对话都在这里）
  manus-cli.exe    命令行 agent
  manus-batch.exe  批量采集 CLI


二、放在哪里
------------------------------------------------
解压到任意有写权限的目录即可，例如：
  D:\ManusGUI\
  C:\Users\<你的用户名>\ManusGUI\

不建议放进 C:\Program Files：那里普通用户没有写权限。
程序会自动降级把配置和运行数据写到 %LOCALAPPDATA%\ManusGUI，
虽然能跑，但配置文件就不在解压目录里了，不好找。


三、首次使用（三步）
------------------------------------------------
第 1 步：右键「启动.ps1」→ 使用 PowerShell 运行
        首次会自动生成 config\config.toml 并用记事本打开。

第 2 步：在记事本里填配置，至少要填：
        [llm] 段
          api_key   模型 API 密钥（必填）
          base_url  API 地址
          model     模型名
        [collect] 段
          采集目标。用云端协作表就填 cloud_file_id；
          用本地 Excel 就留空，之后在界面上选文件。
        填好保存，关掉记事本，回到 PowerShell 窗口按回车。

第 3 步：按提示启动调试 Chrome，然后在里面登录
        Temu 卖家后台和 1688。


四、为什么必须用「启动调试Chrome.ps1」
------------------------------------------------
采集、订单、活动三条管线都不自己开浏览器，而是通过调试端口
接管你已经登录好的那个 Chrome（localhost:9222）。这样才能
复用登录态、绕开平台风控。

所以每次要跑管线之前，Chrome 必须是用这个脚本启动的。

两个容易踩的坑：
  1. 不要用「新建独立 profile」的方式开调试 Chrome。
     那样开出来是全新窗口、没有任何登录态，管线会被踢回登录页。
     脚本用的是你的默认 profile，登录态是现成的。

  2. 启动脚本前必须完全退出 Chrome。
     同一 profile 下只有第一个 Chrome 进程能持有调试端口；
     已经有 Chrome 在跑时再带参数启动，参数会被静默丢弃，
     看起来启动成功、实际端口根本没开。脚本会检测并提示你关闭。

想确认端口是否就绪，浏览器访问：
  http://localhost:9222/json/version
能返回一段 JSON 就说明正常。


五、日常使用
------------------------------------------------
1. 运行「启动调试Chrome.ps1」，在打开的 Chrome 里确认已登录
2. 运行「启动.ps1」
3. 浏览器自动打开 http://127.0.0.1:5172
4. 进「采集」页，选好工作簿和 Sheet，开始采集

批量采集也可以走命令行：
  manus-batch.exe


六、文件都放在哪
------------------------------------------------
config\config.toml       你的配置（含密钥，不要外传）
config\config.example.toml   配置模板，字段说明都在注释里
workspace\               运行状态：判重水位、采集偏好等
logs\                    运行日志，出问题先看这里
experience\              经验库
_internal\               程序依赖，不要改动

采集产物统一落在桌面「manus输出」目录下分类存放：
  Excel备份\ 商品图片\ 调试截图\ 订单采购汇总\ 等

如果解压目录不可写（例如装进了 Program Files），
上面的 config / workspace / logs / experience 会自动改放到：
  %LOCALAPPDATA%\ManusGUI\


七、常见问题
------------------------------------------------
Q: 双击 exe 一闪而过？
A: 请用「启动.ps1」而不是直接双击。直接双击时如果配置缺失，
   错误信息来不及看就关窗了。

Q: 提示 CDP 连不上 / 采集一开始就中止？
A: 调试端口没开。完全退出 Chrome，重新运行「启动调试Chrome.ps1」。

Q: 模型调用报错？
A: 检查 config\config.toml 的 [llm] 段，api_key 是不是还是模板里的占位符。

Q: 采集写不进表？
A: 确认表格没有被 WPS/Excel 占用打开；云端模式确认 cloud_file_id 填对。

Q: 想换个位置放数据？
A: 设环境变量 MANUS_DATA_DIR 指向你想要的目录。
